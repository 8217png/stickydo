# 前端设计规范

> **便捷和美观是前端的第一优先级。** 有取舍时，宁可少做功能，也要把体验打磨到位。

## 1. 设计原则

1. **记录零阻力**：从想到一件事到记下来，不超过 1 秒、1 个动作。
2. **不打断用户**：不弹确认框，不需要点保存，所有操作都可以撤销。
3. **手感好**：每个操作都有即时反馈（乐观更新），动效顺滑而且有意义。
4. **克制的美**：界面安静留白，色彩主要留给便利贴本身。
5. **少即是多**：每个交互都打磨到位，而不是堆砌功能。

## 2. 交互设计（便捷）

### 2.1 快速记录

- **全局快捷输入框**：在任何页面按 `Q`（或点击顶栏的 `+`），屏幕中央弹出输入框，打完字回车就保存。`Ctrl+K` 留给命令面板；在命令面板里输入的文字如果不匹配任何命令，回车时也会按快速记录处理，所以两个入口都能记录。
- **一个输入框同时识别便利贴和待办**：
  - `买牛奶` → 便利贴
  - `[] 买牛奶 明天下午3点 !高 #生活` → 待办，自动解析出时间、优先级和标签
  - 解析到的部分在输入框里实时高亮成小标签，用户在保存前就能确认解析结果
- **识别规则（M3 起）**：只有以 `[]`、`[ ]` 或 `- [ ]` 开头时才是待办，才会去识别下面这些；普通文字原样保存，不会把“今天天气不错”里的“今天”当成日期。
  - 时间：`今天`、`明天`、`后天`、`周三` / `下周一`、`下下周五`、`周末`、`月底`、`5号`、`下个月3号`、`10月20日`、`明天下午3点`、`今晚8点半`、`15:30`；英文 `tomorrow 3pm` 也可以。只说“几点”不说上午下午时，1–7 点按下午算；说不出具体哪天（例如只有“下个月”）的不识别。时间存为不带时区的本地时间：`2026-10-03` 或 `2026-10-03T15:00`。
  - 优先级：`!高` `!中` `!低`，`!!!` / `!!`，或 `!high` `!med` `!low`（简写 `!h` `!m` `!l`）；写了多个以最后一个为准。
  - 标签：`#生活`，前面要有空格或位于开头（`C#` 不算）；全角 `＃` 也可以。
  - 剩下的文字就是待办标题；识别出的时间、优先级、标签显示在便利贴上待办项下方的小标签里，逾期的时间用柔和的橙色。
- **按键**：`Enter` 保存并关闭；`Shift+Enter` 换行；`Ctrl/⌘+Enter` 保存后继续记下一条（刚记的是待办就接着预填 `[] `）；`Esc` 关闭。保存后底部提示条可以撤销，`Ctrl+Z` 也可以。
- **落点**：记录的便利贴放在可见区域里离中央最近的空位，连续记几条不会叠在一起，并自动选中、移到可见处。
- **命令面板（`Ctrl+K`）**：搜索便利贴（回车跳过去并选中）、新建、统一大小、撤销重做、切换主题和倾斜、账号操作；输入的文字不匹配任何命令时，第一项就是“记录为便利贴 / 记录待办”，回车即记录。在编辑便利贴时也能打开。
- 在白板空白处**双击**：直接在当前位置新建便利贴，并立刻进入编辑状态。
- **粘贴即创建**：在白板上 `Ctrl+V` 粘贴文字或链接（二期支持图片），自动生成便利贴。

### 2.2 编辑

- **所见即所得、原地编辑**：没有“编辑模式”和“保存按钮”，内容自动保存。
- **进入编辑**：双击便利贴；或者按住便利贴 2 秒不动，等同于双击。在操作栏、复选框、链接上按住不算。键盘用 `E` 或 `Enter`。
  - 鼠标：按满 2 秒立即进入编辑；按住期间移动超过 5px 算拖动。
  - 触屏（手机、平板）：按满 2 秒时便利贴再放大一点作为提示，**松开手指时**进入编辑——iOS 只在用户手势里允许弹出键盘。手指抖动容差 10px。触屏的移动和松开用 touch 事件跟踪，iOS 中途发 `pointercancel` 不会打断。
  - 白板上的便利贴设置 `touch-action: none` 和 `-webkit-touch-callout: none`（手指在便利贴上滑动是拖动它，不是滚动白板），浏览器不会中途接管这次触摸，也不弹系统的长按菜单；正在编辑时恢复，编辑器里可以滚动、选字。
- Markdown 快捷输入：`[]` 变成复选框，`-` 变成列表，`#` 变成标题。
- **实现（M2 起）**：Tiptap 所见即所得编辑，正文存为 Tiptap JSON（见 architecture.md 数据模型）。
  - Markdown 写法即时变成格式：`# ` 标题、`- ` 列表、`1. ` 有序列表、`> ` 引用、` ``` ` 代码块、`**粗体**`、`*斜体*`、`~~删除线~~`；行首 `[]` 或 `[ ]` 加空格生成待办。列表里回车续行、空项回车结束、`Tab` / `Shift+Tab` 缩进；`Ctrl+B` / `Ctrl+I`。
  - **表格**：在 `| 姓名 | 电话 |` 这样一行的末尾回车，这一行变成表头，下面接一行空的，光标进入第一格；`Tab` / `Shift+Tab` 在格子之间移动，在最后一格按 `Tab` 加一行。只在顶层段落里生效，分隔行（`|---|`）不触发。表格铺满便利贴宽度、各列等宽，长文字在格子里换行。
  - **改表格**：光标在表格里时，便利贴下方出现表格工具栏：「行」上方插入 / 下方插入 / 删除，「列」左侧插入 / 右侧插入 / 删除，以及删除表格。按钮不抢编辑器的焦点，点完继续编辑；正在编辑的便利贴放在最上层，工具栏不会被旁边的便利贴挡住。
    - 快捷键：`Ctrl+Alt+↑ / ↓` 在上方 / 下方插入行，`Ctrl+Shift+Backspace` 删除当前行；`Ctrl+Alt+Shift+← / →` 在左侧 / 右侧插入列，`Ctrl+Alt+Shift+Backspace` 删除当前列（Mac 上 `Ctrl` 换成 `⌘`）。快捷键速查表（`?`）里有。
    - 在一行空行的第一格开头按 `Backspace`：删掉这一行，光标回到上一行末尾（表头不删）。
    - 这些改动和其他编辑一样，结束编辑后整体算一步，`Ctrl+Z` 可以撤销。
  - **粘贴 Markdown 表格**：粘贴的文字里有表格（表头行后面紧跟 `|---|` 分隔行）时，整段按 Markdown 解析，表格直接成为表格（编辑时粘贴、在白板上 `Ctrl+V` 新建都一样）；其他文字照旧原样粘贴。
  - `Esc` 或 `Ctrl/⌘+Enter` 结束编辑，点到别处也会结束；只是打开再关闭不算编辑。
  - 不在编辑状态时，正文由轻量渲染器直接把 JSON 渲染成元素（不挂编辑器，不解析 HTML，链接只允许 http(s) / mailto）；待办的复选框可以直接点击勾选，计入撤销并同步。
  - 第一段作为标题加粗显示（沿用 M0 的约定）。
  - M0/M1 的 Markdown 文本便利贴在第一次打开时自动转换（连续的普通文字行各成一段，标题单独成为第一段）。
- 把待办从便利贴里拖出来，它就成为独立待办；拖进去则合并进便利贴。

### 2.3 零确认 + 撤销

- 删除、归档、完成都**立即生效**，底部弹出提示条：`已删除「买牛奶」 撤销`。
- 全局 `Ctrl+Z` 可以撤销最近 20 步操作，包括移动、改色、删除、勾选待办、移到其他看板，以及看板的新建、改名、删除（删除看板连同其中的便利贴算一步）。

### 2.7 看板与待办视图（M4 起）

- **侧边栏**：今天、即将、已完成；收件箱；看板列表（`+` 新建，悬停出现 `…`：重命名、上移 / 下移、换颜色、删除；上下拖动排序）；标签。宽屏常驻，`[` 收起（专注模式）；窄屏（< 900px，包括插件浮窗）是从左侧滑出的抽屉，选完自动收起，`Esc` 关闭。当前视图、侧边栏开关记在本页。
- **看板**：每个看板是一块独立的白板，收件箱是默认的那块。在哪块白板上新建、快速记录，便利贴就放在哪块（在待办列表里记录的放进收件箱）。统一大小、自动排列、`J`/`K` 切换焦点只作用于当前白板。
- **移到其他看板**：把便利贴拖到侧边栏的看板上（经过时高亮），或者用操作栏上的“移到…”，或者在命令面板里选“移到「工作」”；提示条可以撤销。
- **待办视图**：从所有便利贴里汇总待办项（见 architecture.md「待办的存储」），不需要单独管理。
  - **今天**：已逾期的一组（橙色标题）+ 今天到期的一组，侧边栏显示数量。顶部输入框记的待办没写时间就算今天。
  - **即将**：今天以后的按天分组（“明天 · 10月3日 周六”），最后是“没有日期”。
  - **已完成**：最近编辑过的在前。
  - **标签**：侧边栏列出所有标签和未完成数量；点开是带这个标签的待办，未完成的在前。顶部输入框记的待办自动带上这个标签。
  - 每条显示时间、优先级、标签，以及所在看板和便利贴；排序先按时间（同一天里写了几点的在前），再按优先级。
  - 勾选：先划线，约 0.6 秒后整条平滑收起，提示条“已完成「交周报」 撤销”。点一条待办跳到它所在的白板并选中那张便利贴。
- **搜索**：命令面板搜索所有看板里的便利贴，每条显示所在看板，回车跳过去；也能直接切换到某个看板、视图或标签；输入的文字不匹配时，除了“记录为便利贴”，还可以“新建看板「…」”。
- **账号与设备**（Web，账号菜单或命令面板进入）：修改密码（其他设备随即退出），查看已登录的设备并让某台退出。
- **看板排序**：拖动时只给被移动的看板换一个夹在前后两个之间的排序键（`@stickydo/core/sync` 的 `keyBetween`），其他看板不变，同步时只有一条改动；前后的键有问题（例如两个看板的键相同）时整列重新编号。算一步撤销。

### 2.8 白板 / 列表视图

- 看板右下角“白板 | 列表”切换，快捷键 `V`，命令面板里也有；所有看板共用一个选择，记在本机。
- **列表**：当前看板的便利贴按阅读顺序（先上后下、先左后右，和 `J` / `K` 一样）排成一列，最宽 680px，每张占满一行、高度随内容、不裁切。双击编辑、勾选待办、操作栏（换色、移到看板、删除）、`N` 新建、`J` / `K` 切换焦点都和白板一样；拖动摆放和统一大小只在白板上有。
- 列表不改变便利贴在白板上的位置，切回白板时原样回去；在列表里新建的便利贴，在白板上放在可见区域的空位。
- 切换时同一张便利贴从原来的位置平滑移到新位置（共享元素过渡，motion 的 `layoutId`）；当前看板多于 60 张时直接切换，不做过渡（见 2.6）。

### 2.9 回收站（M5）

- 侧边栏最下面的“回收站”（显示数量），命令面板也能打开。删除的便利贴在这里保留 30 天：卡片显示内容预览、几天前删除、来自哪个看板、几天后清除。
- **恢复**：回到原来的看板（看板已删除就回收件箱），提示条上“查看”跳过去；`Ctrl+Z` 可以撤销恢复。**彻底删除**、**清空回收站**立即生效，提示条可以撤销。
- 撤销删除（`Ctrl+Z` 或提示条）时便利贴直接回来，不会留在回收站里；新建后没写内容就丢弃的空白便利贴不进回收站。
- 在其他设备上删除的便利贴同步过来时也进本机的回收站，在这里恢复后其他设备也会看到它回来。

### 2.10 无边界画布

- 白板没有边界，四个方向都可以无限延伸：便利贴可以放在任何位置（坐标可以是负数），不需要先“扩大画布”。
- **平移**：鼠标不在便利贴上时，按住左键拖动，整块画布连同上面的便利贴一起移动（拖动时显示抓手光标）；中键在哪里按住都可以拖。滚轮 / 触控板双指滑动也平移，`Shift` + 滚轮横向移动；`Ctrl` + 滚轮留给浏览器缩放。触屏上一根手指在空白处拖动。
- 拖动超过 3px 才算平移：在空白处单击仍是取消选中，双击仍是在鼠标位置新建。
- 每块白板记住上次看的位置（记在本机），换看板、刷新后回到原处；第一次打开时便利贴都不在视野里，就移到它们所在的地方。
- 新建（`N`、粘贴、快速记录）落在当前看到的区域；`J` / `K` 切换焦点、从搜索或待办跳到某张便利贴时，画布平滑移动最少的距离把它移进视野；统一大小、自动排列后回到原点。
- 实现：画布图层只改 `transform`（点阵底纹同步改 `background-position`），不触发 React 渲染；平移时用一层透明遮罩显示抓手光标（不给白板加属性再用后代选择器改光标，那样每次开始、结束平移都要重算所有便利贴的样式）。

### 2.4 键盘优先，兼顾鼠标

| 快捷键 | 作用 |
|---|---|
| `Ctrl+K` | 命令面板：搜索所有便利贴、切换看板和视图、执行任何操作 |
| `N` / `T` | 新建便利贴 / 快速记录一条待办（输入框预填 `[] `） |
| `J` `K` / 方向键 | 在卡片之间移动焦点 |
| `Q` | 快速记录 |
| `X` / `E` / `Delete`（或 `Backspace`） | 完成 / 编辑 / 删除 |
| `1`–`8` | 给选中的便利贴换颜色 |
| `-` / `=` | 全部便利贴缩小 / 放大一档并自动排列（见 2.5） |
| `[` | 收起或展开侧边栏（专注模式） |
| `V` | 白板 / 列表视图切换 |
| `?` | 显示快捷键速查表 |

- **单键快捷键的生效条件**：只在焦点不在输入框、文本框或编辑器中，并且输入法不在组字状态（`isComposing`）时生效；在编辑时按 `Esc` 退出编辑，回到卡片焦点。
- **保留符号**：`#`（标签）、`!`（优先级）、`[]`（待办）是快速记录和编辑器里的输入语法，不作为快捷键使用。
- 不占用 `Space`：它保留浏览器默认行为（滚动、勾选当前聚焦的复选框）。

鼠标侧：悬停时出现快捷操作栏（颜色、删除），单张便利贴的尺寸可以拖右下角自由调整；支持右键菜单，以及框选后批量操作。

### 2.5 统一大小与自动排列

- 顶栏有“小 / 中 / 大”三档（160×140、220×200、300×280），快捷键 `-` / `=`。
- 切换档位时，**所有**便利贴统一成该尺寸，并自动排成网格：保持原来大致的先后顺序（先上后下、先左后右），在可见宽度内水平居中，间距留出倾斜和阴影的空间；位置和尺寸平滑过渡。
- 再点一次当前档位，就是“重新排列”。排列从原点开始，画布随之平滑移回原点。
- 排列会覆盖手动摆放的位置，所以整体算一步撤销，提示条上可以直接撤销。
- 当前档位同时是新建便利贴的默认尺寸。

### 2.6 性能即体验

- 操作先写入本地 IndexedDB，UI 立刻更新，目标是 **100ms 内响应**。
- 首屏直接读本地缓存显示，后台静默同步，尽量不出现加载转圈。
- 网络状态只用右上角一个小圆点提示，不打扰用户。
- **M5 打磨**（目标：500 张便利贴也不卡，用生产构建在无 GPU 的 Chromium 里测）：
  - 首屏只加载白板需要的代码（gzip 约 200KB，原来 400KB）：编辑器（Tiptap）、快速记录的解析器（chrono-node）、命令面板（cmdk）、旧版 Markdown 转换、登录 / 账号页都单独打包，白板显示出来后在空闲时预先加载编辑器。编辑器还没加载完时双击编辑，先显示原内容并接住打的字，编辑器拿到焦点后接着写进去，不丢字。
  - 选中、编辑状态由每张便利贴自己订阅：换选中时只有两张重新渲染（原来整块白板都要重渲染，每次约 90ms）。
  - 便利贴的操作栏只在悬停 / 选中时挂载（常驻 500 个毛玻璃操作栏绘制很慢）；拖动时不再给 body 改类名（会让整页重算样式）。
  - 白板 / 列表切换的共享元素过渡、列表和待办的让位动画只在不多于 60 项时启用：动画要测量每个元素的位置，项多时每次渲染都卡。
  - 实测 500 张：首屏全部显示约 1.1 秒；拖动、勾选、编辑最长的一帧都在 100ms 以内，J / K 换选中没有长任务；换到一块 500 张的白板约 0.6 秒（一次挂载所有便利贴，之后如有需要再做只渲染可见区域）。无边界画布（2.10）上拖动、滚轮平移没有长任务。

## 3. 视觉设计（美观）

### 3.1 整体风格

**纸感 + 极简**：浅暖灰背景（像桌面或软木板）配上有真实质感的便利贴；界面框架尽量“隐形”，让内容成为主角。

### 3.2 便利贴质感

- 柔和的多层阴影；拖起来时阴影加深并轻微放大，像真的把纸拿了起来。
- 每张便利贴随机倾斜 ±1.5°（可以在设置中关闭）。
- 极淡的纸张噪点纹理。

### 3.3 动效（Motion）

- 新建：从点击位置以弹簧动画“贴上去”。
- 完成待办：勾选动画、划线，然后整条平滑收起。
- 删除：卡片缩小淡出，周围的卡片自动补位。
- 切换白板/列表视图：卡片之间做共享元素过渡（layout animation）。
- 遵循系统的 `prefers-reduced-motion` 设置，用户关闭动效时自动降级。

### 3.4 排版

- 界面字体：Inter + 系统中文字体（PingFang SC / 思源黑体）。
- 便利贴内容可选手写风格字体（如 LXGW 霞鹜文楷），作为个性化选项。
- 采用 4px 间距体系；圆角、阴影、动效时长全部定义为设计 token。

### 3.5 细节

- **空状态要精心设计**：配插画和一句引导语，例如“双击任意位置，贴上第一张便利贴”。
- 首次使用时，用 3 张示例便利贴代替教程弹窗。
- 逾期待办不刷大红色，只在日期上用柔和的橙色提示。

## 5. 设计 Token
