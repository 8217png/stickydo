# 前端设计规范

> **便捷和美观是前端的第一优先级。** 有取舍时，宁可少做功能，也要把体验打磨到位。

## 1. 设计原则

1. **记录零阻力**：从想到一件事到记下来，不超过 1 秒、1 个动作。
2. **不打断用户**：不弹确认框，不需要点保存，所有操作都可以撤销。
3. **手感好**：每个操作都有即时反馈（乐观更新），动效顺滑而且有意义。
4. **克制的美**：界面安静留白，色彩主要留给便利贴本身。
5. **少即是多**：每个交互都打磨到位，而不是堆砌功能。

## 2. 交互设计（便捷）

### 2.1 快速记录

- **全局快捷输入框**：在任何页面按 `Q`（或点击顶栏的 `+`），屏幕中央弹出输入框，打完字回车就保存。`Ctrl+K` 留给命令面板；在命令面板里输入的文字如果不匹配任何命令，回车时也会按快速记录处理，所以两个入口都能记录。
- **一个输入框同时识别便利贴和待办**：
  - `买牛奶` → 便利贴
  - `[] 买牛奶 明天下午3点 !高 #生活` → 待办，自动解析出时间、优先级和标签
  - 解析到的部分在输入框里实时高亮成小标签，用户在保存前就能确认解析结果
- 在白板空白处**双击**：直接在当前位置新建便利贴，并立刻进入编辑状态。
- **粘贴即创建**：在白板上 `Ctrl+V` 粘贴文字或链接（二期支持图片），自动生成便利贴。

### 2.2 编辑

- **所见即所得、原地编辑**：没有“编辑模式”和“保存按钮”，内容自动保存。
- Markdown 快捷输入：`[]` 变成复选框，`-` 变成列表，`#` 变成标题。
- **实现（M2 起）**：Tiptap 所见即所得编辑，正文存为 Tiptap JSON（见 architecture.md 数据模型）。
  - Markdown 写法即时变成格式：`# ` 标题、`- ` 列表、`1. ` 有序列表、`> ` 引用、` ``` ` 代码块、`**粗体**`、`*斜体*`、`~~删除线~~`；行首 `[]` 或 `[ ]` 加空格生成待办。列表里回车续行、空项回车结束、`Tab` / `Shift+Tab` 缩进；`Ctrl+B` / `Ctrl+I`。
  - `Esc` 或 `Ctrl/⌘+Enter` 结束编辑，点到别处也会结束；只是打开再关闭不算编辑。
  - 不在编辑状态时，正文由轻量渲染器直接把 JSON 渲染成元素（不挂编辑器，不解析 HTML，链接只允许 http(s) / mailto）；待办的复选框可以直接点击勾选，计入撤销并同步。
  - 第一段作为标题加粗显示（沿用 M0 的约定）。
  - M0/M1 的 Markdown 文本便利贴在第一次打开时自动转换（连续的普通文字行各成一段，标题单独成为第一段）。
- 把待办从便利贴里拖出来，它就成为独立待办；拖进去则合并进便利贴。

### 2.3 零确认 + 撤销

- 删除、归档、完成都**立即生效**，底部弹出提示条：`已删除「买牛奶」 撤销`。
- 全局 `Ctrl+Z` 可以撤销最近 20 步操作，包括移动、改色和删除。

### 2.4 键盘优先，兼顾鼠标

| 快捷键 | 作用 |
|---|---|
| `Ctrl+K` | 命令面板：搜索内容、跳转看板、执行任何操作 |
| `N` / `T` | 新建便利贴 / 待办 |
| `J` `K` / 方向键 | 在卡片之间移动焦点 |
| `Q` | 快速记录 |
| `X` / `E` / `Delete`（或 `Backspace`） | 完成 / 编辑 / 删除 |
| `1`–`8` | 给选中的便利贴换颜色 |
| `-` / `=` | 全部便利贴缩小 / 放大一档并自动排列（见 2.5） |
| `[` | 收起或展开侧边栏（专注模式） |
| `?` | 显示快捷键速查表 |

- **单键快捷键的生效条件**：只在焦点不在输入框、文本框或编辑器中，并且输入法不在组字状态（`isComposing`）时生效；在编辑时按 `Esc` 退出编辑，回到卡片焦点。
- **保留符号**：`#`（标签）、`!`（优先级）、`[]`（待办）是快速记录和编辑器里的输入语法，不作为快捷键使用。
- 不占用 `Space`：它保留浏览器默认行为（滚动、勾选当前聚焦的复选框）。

鼠标侧：悬停时出现快捷操作栏（颜色、删除），单张便利贴的尺寸可以拖右下角自由调整；支持右键菜单，以及框选后批量操作。

### 2.5 统一大小与自动排列

- 顶栏有“小 / 中 / 大”三档（160×140、220×200、300×280），快捷键 `-` / `=`。
- 切换档位时，**所有**便利贴统一成该尺寸，并自动排成网格：保持原来大致的先后顺序（先上后下、先左后右），在可见宽度内水平居中，间距留出倾斜和阴影的空间；位置和尺寸平滑过渡。
- 再点一次当前档位，就是“重新排列”。
- 排列会覆盖手动摆放的位置，所以整体算一步撤销，提示条上可以直接撤销。
- 当前档位同时是新建便利贴的默认尺寸。

### 2.6 性能即体验

- 操作先写入本地 IndexedDB，UI 立刻更新，目标是 **100ms 内响应**。
- 首屏直接读本地缓存显示，后台静默同步，尽量不出现加载转圈。
- 网络状态只用右上角一个小圆点提示，不打扰用户。

## 3. 视觉设计（美观）

### 3.1 整体风格

**纸感 + 极简**：浅暖灰背景（像桌面或软木板）配上有真实质感的便利贴；界面框架尽量“隐形”，让内容成为主角。

### 3.2 便利贴质感

- 柔和的多层阴影；拖起来时阴影加深并轻微放大，像真的把纸拿了起来。
- 每张便利贴随机倾斜 ±1.5°（可以在设置中关闭）。
- 极淡的纸张噪点纹理。
- 精选 8 种颜色，并**单独设计暗色版本**：暗色模式下使用降低饱和度的深色调，不是简单反色。暗色便利贴上的文字用暖白 `#EFE9DC`。实际色值以 `web/src/design/tokens.css` 为准。

| 名称 | 浅色 | 暗色（M0 初稿） |
|---|---|---|
| 柠檬黄 | `#FFF4B8` | `#4A4329` |
| 蜜桃 | `#FFD9C7` | `#4D372B` |
| 樱粉 | `#FFD6E7` | `#4A3039` |
| 薰衣草 | `#E5DBFF` | `#3A3450` |
| 天蓝 | `#CDE8FF` | `#2A3D4F` |
| 薄荷 | `#CFF5E1` | `#284339` |
| 沙色 | `#F0E6D6` | `#443B30` |
| 纸白 | `#FAFAF7` | `#3A3936` |

### 3.3 动效（Motion）

- 新建：从点击位置以弹簧动画“贴上去”。
- 完成待办：勾选动画、划线，然后整条平滑收起。
- 删除：卡片缩小淡出，周围的卡片自动补位。
- 切换白板/列表视图：卡片之间做共享元素过渡（layout animation）。
- 遵循系统的 `prefers-reduced-motion` 设置，用户关闭动效时自动降级。

### 3.4 排版

- 界面字体：Inter + 系统中文字体（PingFang SC / 思源黑体）。
- 便利贴内容可选手写风格字体（如 LXGW 霞鹜文楷），作为个性化选项。
- 采用 4px 间距体系；圆角、阴影、动效时长全部定义为设计 token。

### 3.5 细节

- **空状态要精心设计**：配插画和一句引导语，例如“双击任意位置，贴上第一张便利贴”。
- 首次使用时，用 3 张示例便利贴代替教程弹窗。
- 逾期待办不刷大红色，只在日期上用柔和的橙色提示。

## 5. 设计 Token

颜色、阴影、圆角、间距、字体和动效时长统一定义为 CSS 变量，并映射到 Tailwind 主题（放在 `web/src/design/` 下）。后期做 RN 或原生端时，从同一份 token 导出，保证多端风格一致。
