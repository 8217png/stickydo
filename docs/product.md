# 产品功能规划

## 第一期（MVP：Go 服务端 + React Web）

| 模块 | 功能 |
|---|---|
| **账号** | 邮箱注册与登录、JWT 认证、修改密码、退出登录 |
| **便利贴 Note** | 新建、编辑、删除；颜色；**白板模式**（自由拖拽位置、调整大小、层级）与**列表模式**互相切换；置顶；Markdown 快捷格式 |
| **待办 Todo** | 可以独立存在，也可以嵌在便利贴中（便利贴即 checklist）；勾选完成；截止时间；优先级（低、中、高）；一层子任务 |
| **组织** | 看板（Board，如“工作”“生活”）；标签（Tag）；归档；回收站（软删除，30 天后清理） |
| **视图** | 今天、即将到期、已逾期、已完成；全文搜索 |
| **快速记录** | 全局快捷输入框，用自然语言解析时间、优先级和标签（详见 [frontend-design.md](frontend-design.md)） |
| **体验** | 命令面板、全键盘操作、撤销、暗色模式、多标签页实时同步、离线可用 |

## Chrome 插件

- 点击工具栏图标（或 `Alt+Shift+S`）弹出浮窗，功能与 Web 白板一致：便利贴、Markdown 待办、颜色、全局大小与自动排列、撤销
- **不登录、不连服务器也能完整使用**：数据保存在本机（插件自己的存储，与网页版数据互相独立）
- 浮窗可以拖左下角调整大小并记住（Chrome 限制浮窗最大 800×600）；需要更大空间时，一键在**独立窗口**打开，独立窗口可自由调整大小，大小和位置也会记住
- 浮窗和独立窗口同时开着时，内容实时同步
- **登录后与网页版、其他设备同步**（E2）：填自己部署的服务器地址登录，只申请访问这一台服务器的权限；本机已有的便利贴第一次登录时并入账号

## 第二期

- 提醒通知：先做 Web Push，后续接入 APNs/FCM
- 重复任务（RRULE，如每天、每周一）
- 附件与图片（对象存储）
- 共享看板与多人协作（便利贴正文引入 CRDT/Yjs）
- 导入与导出（JSON、Markdown）

## 第三期（移动端）

- Android 与 iOS 客户端，**离线优先**
- 桌面小组件（Widget）：展示今日待办和便利贴
- 第三方登录（Apple、Google、微信）
