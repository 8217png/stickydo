# 里程碑与待决事项

## 第一期里程碑

设计系统前置，功能按体验价值排序；服务端开发与前端并行，节奏跟着前端的需求走。

| 阶段 | 内容 | 预估 |
|---|---|---|
| M0 | **视觉原型**：只有白板和便利贴的单页（拖拽、配色、动效），先把手感调到满意 | 3–5 天 |
| M1 | 设计 token、基础组件（Storybook）、注册登录页；服务端脚手架、OpenAPI、数据库迁移、认证 | 1 周 |
| M2 | **白板 + 便利贴**：双击新建、拖拽、颜色、原地编辑、动效；对应的 CRUD 接口 | 1–2 周 |
| M3 | **快速记录**：全局输入框、自然语言解析、命令面板、快捷键 | 1–2 周 |
| M4 | 待办视图（今天、即将、已完成）、看板与标签、撤销系统、空状态、搜索 | 1–2 周 |
| M5 | 离线同步 + WebSocket 实时更新、暗色模式、性能打磨、回收站、Docker 部署 | 1–2 周 |
