# Sticky-Do 设计文档

Sticky-Do 是一款「便利贴 + 待办事项」应用。

- 第一期：Go 服务端 + React Web 前端
- 后期：Android 与 iOS 客户端

## 核心原则

1. **前端以便捷和美观为第一优先级**：在功能与体验之间取舍时，优先保证体验。
2. **API First、多端就绪**：虽然第一期只做 Web，但接口、认证和同步协议从一开始就按照多端（含离线）来设计。
